

# Safe-Her ♀
### Your Safety, Your Route.

Safe-Her is a smart women safety navigation web application designed to help users compare available routes using community-reported safety information.

## Problem Statement

People often choose the shortest route without knowing about possible safety concerns such as harassment, poor street lighting or isolated areas.

Safe-Her aims to make route selection more safety-aware.

## Key Features

- Smart route search
- Multiple route comparison
- Community-based safety scoring
- Unsafe area reporting
- Interactive map
- GPS location support
- Emergency call assistance
- Privacy-conscious reporting

## Installation

1. Clone this repository.

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

2. Open the project folder.

3. Install dependencies.

```bash
pip install -r requirements.txt
```

4. Run the application.

```bash
python app.py
```

5. Open in browser:

```text
http://127.0.0.1:5000
```

## Safety Disclaimer

Safety scores are based on available community reports and do not guarantee personal safety. Missing reports do not indicate that an area is safe.
